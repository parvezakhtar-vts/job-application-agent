# Professional Writing

A style reference for polishing any professional prose. Apply it as a final pass on
resumes, cover letters, outreach messages, and similar documents.

## Core principles
- **Clarity over cleverness.** One idea per sentence. Cut words that don't earn space.
- **Active voice, strong verbs.** "Built", "led", "cut", "scaled" — not "was
  responsible for", "helped with", "worked on".
- **Show with specifics.** Numbers, scope, outcomes. "Cut p95 latency 20%" beats
  "improved performance significantly".
- **Confident, not boastful.** State impact plainly; let results carry the weight.
- **Reader-first.** Lead with what matters to the reader (the employer's need), not a
  chronological autobiography.

## Resume bullet formula
`[Strong verb] + [what you did] + [tech/how] + [quantified impact]`
- Start every bullet with an action verb; vary them, avoid repeats.
- Front-load the result when it's the strongest part.
- Keep bullets to 1–2 lines. If it wraps to a third line, trim.

## Editing checklist (run on the final draft)
- [ ] Remove filler: "very", "really", "in order to", "basically", "I think",
      "responsible for", "successfully", "various".
- [ ] Kill clichés: "team player", "go-getter", "passionate about", "fast-paced
      environment", "results-driven", "synergy", "think outside the box".
- [ ] No weak hedges: "helped", "assisted", "involved in" → name what *you* did.
- [ ] No em dashes (`—`): use commas, colons, parentheses, or split into two sentences.
- [ ] Consistent tense (past for prior roles, present for current).
- [ ] Consistent punctuation, capitalization, and number style (e.g., always "20%"
      or always "20 percent" — don't mix).
- [ ] Parallel structure in lists.
- [ ] No unexplained jargon or acronyms on first use (unless ATS keyword).
- [ ] Spell out the value: every sentence answers "so what?".
- [ ] Read it aloud — if you stumble, rewrite.

## Tone calibration
- **Formal** (enterprise, finance, legal): full sentences, restrained, precise.
- **Conversational** (startups, product roles): warmer, still concise, a little voice.
- Match the tone of the target company's own writing (careers page, JD voice).

## Common fixes
| Weak | Strong |
|------|--------|
| Responsible for managing the pipeline | Owned and scaled the data pipeline to 50k msgs/day |
| Helped improve performance | Cut p95 API latency 20% by removing N+1 queries |
| Worked on a team that built X | Led 3 engineers to ship X |
| Passionate about AI | (delete — show it with what you built) |

Keep edits truthful: tighten and sharpen wording, never inflate facts or metrics.
